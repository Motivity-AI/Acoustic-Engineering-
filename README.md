## العربية

### 🎯 نظرة عامة

**AURALIS** هي مجموعة أدوات تصميم صوتي احترافية تعمل بالكامل في المتصفح، تتيح لك:

- 🏗️ **تصميم 44 بيئة صوتية** (مساجد، مسارح، ملاعب، مطارات، شوارع، حدائق، مسابح، حلبات، ملاعب غولف، حدائق حيوانات، قاعات اجتماعات، والمزيد)
- 🔊 **محاكاة انتشار الصوت** في الوقت الحقيقي مع خريطة حرارية حية
- 📐 **حساب SPL** (مستوى ضغط الصوت) بدقة فيزيائية مع اتجاهية ومسافة
- 🎛️ **مكتبة شاملة من 60+ جهاز** من 13 ماركة عالمية
- 📄 **تصدير تقارير هندسية** احترافية بصيغة PDF
- 💾 **حفظ ومشاركة** تصاميمك بصيغة JSON
- 🌍 **واجهة ثنائية اللغة** (عربي/إنجليزي) مع RTL/LTR كامل
