# 🎯 Acoustic Engineering — Unified Platform

نظام هندسي متكامل لتصميم أنظمة الصوت، يعمل بثلاثة أوضاع تلقائياً:

| الوضع | المتطلب | الميزات |
|------|---------|---------|
| **Firebase Cloud** | تهيئة Firebase | مزامنة سحابية، PWA، عمل offline |
| **Local Server** | Node.js + SQLite | تقارير PDF حقيقية، ملفات، بدون إنترنت |
| **Local Storage** | متصفح فقط | عمل فوري، لا يحتاج إعداد |
